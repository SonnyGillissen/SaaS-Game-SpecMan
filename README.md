# SaaS-Game-SpecMan

SpecMan is a vanilla HTML/CSS/JavaScript retro platformer inspired by classic console games.

## Play
- Open `index.html` in a browser.
- Move with `←` / `→`
- Jump with `Space`
- Dash with `Z`
- Shoot with `X`
- Toggle sound with `M`
- Save progress with `P` or **Save Progress** button

## Features
- Six integration lifecycle levels: Discovery, Requirements, Planning, Developing, Testing, Go Live
- Boss encounters including AI, Dissatisfied Users, Organizational Culture, Faulty Middlemanagement, and more
- Multiple themed power-ups (Developer Velocity, Stakeholder Management, Management Back Up, Additional Budget, etc.)
- Shooting mechanic: press X to fire — bullets kill minions and chip boss HP
- Coins and heart pickups scattered across each stage
- Power-ups act as a buffer: taking a hit consumes an active power-up before reducing HP
- 8-bit style procedural sound effects and looping background tune
- Sound on/off toggle
- Local save system via `localStorage`
- Sonny as a Service branding
